# Privacy Policy for Windows Services Search

Last updated: September 20, 2026

Windows Services Search does not collect, store, transmit, sell, or share personal information.

## Information Accessed

Windows Services Search reads the following information about Windows services installed on the user's device:

- Display name
- Service name
- Description
- Current status
- Startup type

This information is used only to provide local search results. It remains on the user's device and is not transmitted to the developer or any third party.

## Diagnostic Logs

Windows Services Search may create diagnostic log files on the user's device to record the results of opening and navigating the Windows Services management console.

These logs may contain operational and error information. They remain on the user's device and are never transmitted automatically.

## Network Communication

Windows Services Search does not use an internet connection for searching Windows services or opening service properties.

## Administrator Privileges

Windows Services Search may request administrator privileges through Windows User Account Control (UAC) when opening the properties dialog for a selected service.

Administrator privileges are used only to interact with the standard Windows Services management console. Windows Services Search does not start, stop, restart, delete, or modify the configuration of any service.

## Third-Party Sharing

Windows Services Search does not sell, rent, share, or disclose user information to third parties.

## Changes to This Policy

This privacy policy may be updated when the application's functionality changes. Any revisions will be published on this page with an updated revision date.
